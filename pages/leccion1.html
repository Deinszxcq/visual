1) ¿Qué es una expresión?

Una expresión es una combinación de valores, variables y operadores que al evaluarse produce un resultado. En programación, una expresión “se resuelve” y devuelve un valor final.

Tipo

Aritmética

Ejemplo: 5 + 3 → 8

Tipo

Relacional

Ejemplo: 10 > 2 → true

Tipo

Lógica

Ejemplo: true && false → false

Ejemplos (JavaScript):

// Expresión aritmética
let total = 20 + 5;

// Expresión relacional (devuelve true/false)
let esMayor = 10 > 3;

// Expresión lógica (combina true/false)
let puedeEntrar = (edad >= 18) && (tieneCedula === true);

Explicación: cada línea “se evalúa” y da un resultado. Por ejemplo, 10 > 3 devuelve true.

2) Tipos de operadores

2.1 Aritméticos

Sirven para operaciones matemáticas.

// +  -  *  /  %
let a = 10 + 5;   // 15
let b = 10 - 5;   // 5
let c = 10 * 2;   // 20
let d = 10 / 2;   // 5
let e = 10 % 3;   // 1 (residuo)

2.2 Relacionales

Comparan valores y devuelven true/false.

// >  <  >=  <=  ==  ===  !=
let r1 = 5 > 3;      // true
let r2 = 5 <= 3;     // false
let r3 = 5 == "5";   // true (compara sin tipo)
let r4 = 5 === "5";  // false (compara con tipo)

2.3 Lógicos

Unen condiciones (true/false).

// && (y)  || (o)  ! (negación)
let l1 = (10 > 5) && (3 < 1); // false
let l2 = (10 > 5) || (3 < 1); // true
let l3 = !(10 > 5);           // false

2.4 Asignación

Guardan valores en variables.

// =  +=  -=  *=  /=
let x = 10;
x += 5; // x = x + 5 → 15
x -= 2; // 13
x *= 2; // 26
x /= 2; // 13

Objetivo: Crear una función que reciba un nombre y devuelva un saludo.

Ejercicio 2: Sumar dos números

Objetivo: Crear una función que reciba 2 números y retorne su suma.

  1. Crear una función sumar.
  2. Recibir a y b.
  3. Retornar a + b.
function sumar(a, b) {
  return a + b;
}
console.log(sumar(5, 3));

Ejercicio 3: Calcular IVA (12%)

Objetivo: Dado un precio, calcular el IVA y el total.

  1. Crear una función calcularTotal.
  2. Recibir precio.
  3. IVA = precio * 0.12
  4. Total = precio + IVA
function calcularTotal(precio) {
  const iva = precio * 0.12;
  const total = precio + iva;
  return { iva, total };
}

console.log(calcularTotal(10));

Ejercicio 4: Par o impar

Objetivo: Función que retorne "Par" o "Impar".

  1. Crear función parImpar.
  2. Recibir n.
  3. Si n % 2 == 0 → Par, si no → Impar.
function parImpar(n) {
  return (n % 2 === 0) ? "Par" : "Impar";
}
console.log(parImpar(10));

4) Jetpack Compose: Text reutilizable (1 punto)

Aquí creamos un Composable reutilizable que muestra nombre, edad y carrera.

Código (Kotlin - Jetpack Compose):

@Composable
fun TextInfo(label: String, value: String) {
    // Este composable es reutilizable porque lo puedes usar muchas veces
    Text(
        text = "$label: $value",
        style = MaterialTheme.typography.bodyLarge
    )
}

@Composable
fun Perfil() {
    Column {
        TextInfo("Nombre", "Josué Jacome")
        TextInfo("Edad", "18")
        TextInfo("Carrera", "Programación Visual")
    }
}

Explicación: TextInfo recibe 2 parámetros (label y value) y lo puedes reutilizar para cualquier dato.

5) Jetpack Compose: Calculadora básica (2 puntos)

Calculadora con 4 operaciones: sumar, restar, multiplicar y dividir.

Código (Kotlin - Jetpack Compose):

@Composable
fun CalculadoraBasica() {
    var n1 by remember { mutableStateOf("") }
    var n2 by remember { mutableStateOf("") }
    var resultado by remember { mutableStateOf("") }

    fun toDoubleOrNullSafe(text: String): Double? {
        // Si el texto no es número, devuelve null
        return text.toDoubleOrNull()
    }

    Column(verticalArrangement = Arrangement.spacedBy(10.dp)) {

        OutlinedTextField(
            value = n1,
            onValueChange = { n1 = it },
            label = { Text("Número 1") }
        )

        OutlinedTextField(
            value = n2,
            onValueChange = { n2 = it },
            label = { Text("Número 2") }
        )

        Row(horizontalArrangement = Arrangement.spacedBy(10.dp)) {

            Button(onClick = {
                val a = toDoubleOrNullSafe(n1)
                val b = toDoubleOrNullSafe(n2)
                resultado = if (a != null && b != null) (a + b).toString() else "Ingresa números válidos"
            }) { Text("+") }

            Button(onClick = {
                val a = toDoubleOrNullSafe(n1)
                val b = toDoubleOrNullSafe(n2)
                resultado = if (a != null && b != null) (a - b).toString() else "Ingresa números válidos"
            }) { Text("-") }

            Button(onClick = {
                val a = toDoubleOrNullSafe(n1)
                val b = toDoubleOrNullSafe(n2)
                resultado = if (a != null && b != null) (a * b).toString() else "Ingresa números válidos"
            }) { Text("×") }

            Button(onClick = {
                val a = toDoubleOrNullSafe(n1)
                val b = toDoubleOrNullSafe(n2)
                resultado = if (a != null && b != null) {
                    if (b == 0.0) "No se puede dividir para 0" else (a / b).toString()
                } else "Ingresa números válidos"
            }) { Text("÷") }
        }

        Text(text = "Resultado: $resultado")
    }
}

Explicación: se convierten los textos a número con toDoubleOrNull(). Si no son válidos, muestra error.
