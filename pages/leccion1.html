¿Qué es POO?

La Programación Orientada a Objetos (POO) es un paradigma donde el código se organiza como objetos del mundo real: usuarios, autos, cuentas, productos, etc.

  • Clase: el molde o plantilla
  • Objeto: una instancia creada desde la clase
  • Permite código más ordenado, reutilizable y mantenible

Clases y Objetos

Una clase es una plantilla con atributos y métodos. 

class Persona {
  String nombre;
  int edad;

  void saludar() {
    System.out.println("Hola soy " + nombre);
  }
}

Herencia

Permite que una clase hija herede propiedades de una clase padre. 

class Animal {
  String nombre;
}

class Perro extends Animal {
  void ladrar() {
    System.out.println("Guau");
  }
}

Polimorfismo

Un mismo método puede comportarse distinto según el objeto. 

class Animal {
  void sonido() {
    System.out.println("Sonido");
  }
}

class Perro extends Animal {
  void sonido() {
    System.out.println("Guau");
  }
}

Clases Abstractas

Son clases base que no pueden instanciarse y obligan a implementar métodos. 

abstract class Figura {
  abstract double area();
}

class Cuadrado extends Figura {
  double lado;

  double area() {
    return lado * lado;
  }
}
