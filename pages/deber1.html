1) ¿Qué son las sentencias de control?

Las sentencias de control son instrucciones que permiten decidir qué parte del código se ejecuta o repetir acciones varias veces. Básicamente, ayudan a que un programa no sea “lineal”, sino que pueda tomar decisiones según una condición y manejar diferentes caminos.

✅ Control de decisión

El programa elige entre opciones (ej: if, else, switch).

🔁 Control de repetición

El programa repite algo (ej: for, while, do while).

2) Tipos de sentencias y su sintaxis

2.1) if / else

Se usa cuando quieres ejecutar algo solo si se cumple una condición.

Sintaxis:

if (condicion) {
  // código si la condición es verdadera
} else {
  // código si la condición es falsa
}

2.2) else if

Se usa cuando tienes varias condiciones en cadena.

Sintaxis:

if (condicion1) {
  // ...
} else if (condicion2) {
  // ...
} else {
  // ...
}

2.3) switch

Se usa cuando una variable puede tener varios casos posibles.

Sintaxis:

switch (valor) {
  case 1:
    // ...
    break;
  case 2:
    // ...
    break;
  default:
    // ...
}

2.4) for

Repite un bloque un número de veces (tiene inicio, condición y aumento).

Sintaxis:

for (inicio; condicion; aumento) {
  // código que se repite
}

2.5) while

Repite mientras la condición sea verdadera (si empieza falsa, no entra).

Sintaxis:

while (condicion) {
  // se repite mientras sea true
}

2.6) do while

Se ejecuta al menos una vez y luego repite mientras la condición sea verdadera.

Sintaxis:

do {
  // se ejecuta mínimo 1 vez
} while (condicion);

3) Ejercicios prácticos

2 ejercicios sencillos usando sentencias de control (en estilo JavaScript).

✅ Ejercicio 1: Clasificar una nota

Crea un programa que reciba una nota (0 a 10) y muestre: “Aprobado” si es 7 o más, y “Reprobado” si es menor.

Código:

let nota = 8;

if (nota >= 7) {
  console.log("Aprobado");
} else {
  console.log("Reprobado");
}

Explicación rápida: si nota >= 7 es verdadero, imprime “Aprobado”. Si no, imprime “Reprobado”.

✅ Ejercicio 2: Tabla de multiplicar con for

Un programa que muestre la tabla de multiplicar de un número (del 1 al 10).

Código:

let n = 5;

for (let i = 1; i <= 10; i++) {
  console.log(n + " x " + i + " = " + (n * i));
}

Explicación rápida: el for repite desde i = 1 hasta i = 10 y muestra cada multiplicación.
