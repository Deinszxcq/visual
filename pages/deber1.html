Paso 1: Definimos una función async. Esto permite que el navegador no se bloquee mientras espera los datos del servidor.

Paso 2: Usamos fetch(url). Es la instrucción de JavaScript que viaja a la nube para traer el paquete de datos (JSON).

Paso 3: Convertimos la respuesta con .json(). Los datos llegan como texto y debemos transformarlos en una lista de objetos legible.

Paso 4: Pintamos el HTML. Usamos un ciclo forEach para crear una tarjeta visual por cada usuario recibido y la insertamos en el DOM.
