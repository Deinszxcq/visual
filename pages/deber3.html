1) ¿Qué son clases y objetos?

En POO, una clase es como un molde o plantilla que define cómo será algo (sus datos y sus acciones). Un objeto es una instancia de esa clase (es decir, un “ejemplar” real creado con ese molde).

📌 Clase

Define atributos (datos) y métodos (acciones).

✅ Objeto

Es lo que se crea a partir de la clase y se usa en el programa.

Ejemplo rápido en JavaScript (Clase y Objeto):

class Persona {
  constructor(nombre, edad) {
    this.nombre = nombre;
    this.edad = edad;
  }

  presentarse() {
    return "Hola, soy " + this.nombre + " y tengo " + this.edad + " años.";
  }
}

const p1 = new Persona("Josué", 18);
console.log(p1.presentarse());

2) Los 4 pilares de la POO

2.1 Encapsulamiento

Consiste en proteger los datos del objeto y permitir acceso solo mediante métodos. (Ej: getters y setters). 

class Cuenta {
  #saldo = 0; // privado

  depositar(monto) { this.#saldo += monto; }
  verSaldo() { return this.#saldo; }
}

2.2 Abstracción

Es quedarse con lo importante del problema y ocultar detalles innecesarios. (Modelar lo esencial). 

// Abstraemos un "Auto" con lo esencial:
class Auto {
  constructor(marca) { this.marca = marca; }
  encender() { return "Auto encendido"; }
}

2.3 Herencia

Una clase puede heredar atributos y métodos de otra. Así se reutiliza código. 

class Animal {
  hacerSonido() { return "Sonido"; }
}

class Perro extends Animal {
  hacerSonido() { return "Guau"; }
}

2.4 Polimorfismo

Un mismo método puede comportarse de forma distinta dependiendo del objeto. 

const animales = [new Animal(), new Perro()];
animales.forEach(a => console.log(a.hacerSonido()));

3) Ejercicios prácticos aplicando POO

En estos ejercicios, la idea es mostrar tu razonamiento: identificar objetos, atributos y métodos.

✅ Ejercicio 1: Sistema de Estudiante

Código:

class Estudiante {
  constructor(nombre, notas) {
    this.nombre = nombre;
    this.notas = notas; // arreglo
  }

  promedio() {
    let suma = 0;
    for (let n of this.notas) suma += n;
    return suma / this.notas.length;
  }

  estado() {
    return this.promedio() >= 7 ? "Aprobado" : "Reprobado";
  }
}

const e1 = new Estudiante("Josué", [8, 7, 9]);
console.log("Promedio:", e1.promedio());
console.log("Estado:", e1.estado());

✅ Ejercicio 2: Cuenta Bancaria (Encapsulamiento)

Problema: Crear una clase CuentaBancaria con saldo privado y métodos: depositar(), retirar() y verSaldo().

Código:

class CuentaBancaria {
  #saldo;

  constructor(saldoInicial) {
    this.#saldo = saldoInicial;
  }

  depositar(monto) {
    if (monto > 0) this.#saldo += monto;
  }

  retirar(monto) {
    if (monto > 0 && monto <= this.#saldo) {
      this.#saldo -= monto;
      return "Retiro exitoso";
    }
    return "No se puede retirar";
  }

  verSaldo() {
    return this.#saldo;
  }
}

const cuenta = new CuentaBancaria(50);
cuenta.depositar(25);
console.log("Saldo:", cuenta.verSaldo());
console.log(cuenta.retirar(40));
console.log("Saldo final:", cuenta.verSaldo());
