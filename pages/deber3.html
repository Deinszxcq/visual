Deber 3: CRUD utilizando Realtime Database

Desarrolla operaciones completas de Crear, Leer, Actualizar y Eliminar utilizando Firebase Realtime Database.

// Ciclo de vida del CRUD:

Create (Crear): Se usa la función push() o set() para enviar un nuevo objeto JSON a una ruta específica de la base de datos.

Read (Leer): Utilizamos onValue() para escuchar cambios en tiempo real. Si un dato cambia en la nube, la interfaz se actualiza sola sin refrescar.

Update (Actualizar): Mediante el método update(), modificamos solo los campos necesarios de un registro existente usando su ID único.

Delete (Eliminar): La función remove() elimina el nodo completo de la base de datos de forma instantánea.
