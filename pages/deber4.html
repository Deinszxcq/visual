Deber 4: CRUD utilizando Room

Implementa operaciones CRUD utilizando la biblioteca Room para persistencia de datos local.

// Arquitectura de Persistencia Local:

1. Entity (Entidad): Definimos la tabla. Cada clase anotada con @Entity representa una tabla en la base de datos SQLite interna del celular.

2. DAO (Data Access Object): Es la interfaz donde escribimos las consultas SQL. Usamos @Insert, @Query, @Update y @Delete.

3. Room Database: Es el punto de acceso principal. Gestiona las conexiones y asegura que los datos sean consistentes incluso si el app se cierra.

4. Ventaja: A diferencia de una API, Room funciona **sin internet**. Los datos se quedan guardados físicamente en el almacenamiento del dispositivo.
